# skills

A repository of skills I create or find interesting.

## Skills

 - **[mac-arsed-mac-app](mac-arsed-mac-app/SKILL.md)** — Design, build, review, or refactor native macOS apps that genuinely follow Mac conventions, rather than web/Electron/iPad apps merely packaged for macOS. This skill collects existing community principles rather than originating them. The term "Mac-assed Mac app" was coined by Collin Donnell and popularised by Brent Simmons ([Daring Fireball, 2020](https://daringfireball.net/linked/2020/03/20/mac-assed-mac-apps)); the [Accidental Tech Podcast](https://atp.fm) "ATP Dev" episode "Mac-Assed Mac Apps" (28 June 2026) is the main basis for the discussion, with the SwiftUI/AppKit specifics drawn from [Paulo Andrade's post](https://pfandrade.me/blog/mac-assed-swiftui-app/). Full attributions are in the skill's Sources section.
